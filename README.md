# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №22.

## Этап 1. REPL

На первом этапе реализован минимальный прототип эмулятора
UNIX-подобной командной оболочки.

Программа поддерживает:

- консольный интерфейс;
- приглашение к вводу с именем VFS;
- разбор команды и аргументов по пробелам;
- команду-заглушку `ls`;
- команду-заглушку `cd`;
- команду `exit`;
- обработку неизвестных команд;
- обработку неверных аргументов.

## Структура проекта

- `src/` — исходный код;
- `tests/` — автоматические тесты;
- `run.bat` — скрипт запуска;
- `README.md` — документация;
- `.gitignore` — список файлов, исключённых из Git.

## Запуск

В Windows:

```powershell
.\run.bat
```

Или:

```powershell
py src/main.py
```

## Примеры использования

```text
my_vfs:~$ ls
ls []

my_vfs:~$ ls abc
ls ['abc']

my_vfs:~$ cd documents
cd ['documents']

my_vfs:~$ cd
Ошибка: команда cd ожидает один аргумент

my_vfs:~$ abracadabra
Ошибка: неизвестная команда: abracadabra

my_vfs:~$ exit
```

## Тестирование

Для запуска тестов:

```powershell
py -m unittest discover -s tests
```
