# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №22.

## Общее описание

Проект представляет собой консольный эмулятор UNIX-подобной
командной оболочки.

Эмулятор написан на Python и запускается в Windows через файл
`run.bat`.

На текущий момент реализованы этапы:

- Этап 1. REPL;
- Этап 2. Конфигурация.

## Этап 1. REPL

Реализован минимальный прототип эмулятора командной оболочки.

Поддерживаются:

- консольный интерфейс;
- приглашение к вводу с именем VFS;
- разбор команды и аргументов по пробелам;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка неверных аргументов.

## Этап 2. Конфигурация

Реализована передача параметров при запуске программы.

Поддерживаются параметры:

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту.

При запуске программа выводит значения полученных параметров.

На данном этапе существование пути к VFS не проверяется.
Проверяется только существование файла стартового скрипта.

Если указан стартовый скрипт, команды из него выполняются
последовательно.

При выполнении стартового скрипта:

- команда отображается на экране перед выполнением;
- отображается результат выполнения команды;
- пустые строки пропускаются;
- строки, начинающиеся с `#`, считаются комментариями;
- при первой ошибке выполнение скрипта прекращается;
- при ошибке выводится номер строки;
- команда `exit` завершает работу эмулятора.

## Структура проекта

- `src/` — исходный код программы;
- `src/main.py` — основной файл эмулятора;
- `tests/` — тесты и тестовые сценарии;
- `tests/test_main.py` — автоматические тесты Python;
- `tests/start_ok.txt` — успешный стартовый сценарий;
- `tests/start_error.txt` — сценарий с ошибочной командой;
- `tests/test_default.bat` — тест запуска со стартовым скриптом;
- `tests/test_parameters.bat` — тест параметров командной строки;
- `tests/test_invalid_script.bat` — тест отсутствующего скрипта;
- `run.bat` — основной скрипт запуска программы;
- `README.md` — документация проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Запуск

Обычный запуск:

```powershell
.\run.bat
```

Или напрямую через Python:

```powershell
py src\main.py
```

## Параметры командной строки

Передача пути к VFS:

```powershell
.\run.bat --vfs my_vfs
```

Передача стартового скрипта:

```powershell
.\run.bat --script tests\start_ok.txt
```

Одновременная передача двух параметров:

```powershell
.\run.bat --vfs my_vfs --script tests\start_ok.txt
```

## Примеры интерактивного режима

```text
my_vfs:~$ ls
ls []

my_vfs:~$ ls abc
ls ['abc']

my_vfs:~$ cd documents
cd ['documents']

my_vfs:~$ cd
Ошибка: команда cd ожидает один аргумент

my_vfs:~$ abracadabra
Ошибка: неизвестная команда: abracadabra

my_vfs:~$ exit
```

## Пример стартового скрипта

Файл:

```text
ls
cd documents
ls
exit
```

Запуск:

```powershell
.\run.bat --script tests\start_ok.txt
```

Пример результата:

```text
VFS: (не указан)
Скрипт: tests\start_ok.txt
my_vfs:~$ ls
ls []
my_vfs:~$ cd documents
cd ['documents']
my_vfs:~$ ls
ls []
my_vfs:~$ exit
```

## Обработка ошибки в стартовом скрипте

Пример:

```text
ls
unknown_command
cd documents
exit
```

После выполнения `unknown_command` эмулятор сообщает об ошибке
и прекращает выполнение последующих команд.

## Тестирование

Автоматические тесты Python:

```powershell
py -m unittest discover -s tests
```

Тест успешного запуска:

```powershell
.\tests\test_default.bat
```

Тест параметров командной строки:

```powershell
.\tests\test_parameters.bat
```

Тест отсутствующего стартового скрипта:

```powershell
.\tests\test_invalid_script.bat
```

Также стартовый сценарий с ошибкой можно проверить командой:

```powershell
.\run.bat --script tests\start_error.txt
```
